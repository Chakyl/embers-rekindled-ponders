This is a library of ponders available for the [Embers Rekindled](https://www.curseforge.com/minecraft/mc-mods/embers-rekindled) mod. It is intended to be used by modpack developers or players to better document the mod with visual explanations.

Information in these ponders is up to date with these versions:
- Embers Rekindled version [1.20.1-1.3.11](https://www.curseforge.com/minecraft/mc-mods/embers-rekindled/files/6156839)
- Aetherworks Refracted version [1.20.1-1.1.3](https://www.curseforge.com/minecraft/mc-mods/aetherworks-refracted/files/6207883)

## Dependencies

Before you do anything else, ensure the following mods are installed in your instance:

- [KubeJS](https://www.curseforge.com/minecraft/mc-mods/kubejs) and its dependencies 
- [Embers Rekindled](https://www.curseforge.com/minecraft/mc-mods/embers-rekindled)
- [Aetherworks Refracted](https://www.curseforge.com/minecraft/mc-mods/aetherworks) - Optional

If you have [Create](https://www.curseforge.com/minecraft/mc-mods/create) installed already, install:
- [Ponder for KubeJS](https://www.curseforge.com/minecraft/mc-mods/ponder)

If you *don't have or won't add* Create, install:
- [Create Ponder](https://www.curseforge.com/minecraft/mc-mods/create-ponder) - A standalone mod for the Ponder functionality without Create

## Installation 

1. Download the repo as a zip

2. Extract the zip and move `kubejs/assets` and `kubejs/client_scripts` into your modpack's `kubejs` folder

3. If not using Aetherworks Refracted, remove all ponders in the `client_scripts/ponders/aetherworks` folder and all Aetherworks ponder tags in `client_scripts/ponders/ponderTags.js `

4. Restart the game

## How to Contribute

For simple changes like typos or information fixes, feel free to create a pull request!

If you'd like to do something larger and more structural, it's best to inform me ahead of time in the issues tab or on [Discord](https://discord.gg/GdcZkrZqkj).

That's not to say you can't submit a pull request without doing so- this is more to prevent wasted effort if I'm also working on a large structural change at the same time.
